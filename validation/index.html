# 둘러방 백엔드 v1.1 확장 검증 결과

검증일: 2026-10-01 · API 계약 1.1.0 유지 · Windows, Python 3.13.2 / 3.12.14.

## 실제 결과

- 최종 전체 테스트: **513 passed**, 실패 0. Python 3.13과 3.12에서 각각 실행했습니다.
- 추가 세부 검사: **19,600 passed**. 스키마·HTTP 부정 입력 14,860회, 선언된 enum·수치·문자 길이·boolean 정상 경계 4,740회입니다.
- **59/59 API** 정상 응답과 오류 응답을 관찰했습니다. HTTP 요청 총 4,323회, 106개 모델을 검증했습니다.
- 최종 소스 커버리지: 실행문 **98.36%**, 분기 **92.88%**, 합산 **97.20%**.
- 실제 Uvicorn TCP + 제공한 WorkerClient: 촬영 업로드, claim, 13개 입력 파일 다운로드, heartbeat/URL 갱신, 결과 업로드, 완료 및 동일 callback 재전송 통과.
- 실제 TCP 동시 요청: 같은 키 생성 8회→리소스 1개, 동일 ETag 수정 8회→성공 1개/412 7개, 동시성 8로 읽기 64회→전부 성공.
- 실제 서버 프로세스 종료/재시작 후 세션·모델·파일·대기 작업 유지 및 워커 claim 통과.
- Ruff check/format 통과. 기존 Starlette TestClient의 httpx 사용 deprecation warning 1건은 남아 있습니다.

**숫자의 의미:** 513은 pytest 테스트 항목 수이고 19,600은 그 안의 세부 검사 수입니다. 중첩 모델 및 여러 API에서 같은 공통 조건을 반복한 검사도 포함합니다. 19,600개의 서로 다른 업무 시나리오라는 뜻은 아닙니다. 모든 가능한 값·순서·동시 실행 조합이나 결함 부재를 증명하지 않습니다.

## 발견해 수정한 문제

1. GLB 내부 JSON이 배열·null·잘못된 중첩 구조일 때 일부 예외가 500으로 이어졌습니다. 이제 INVALID_ARTIFACT 422로 처리합니다.
2. 카카오의 만료/회원번호·profile 응답 타입 및 구글 JWKS 구조가 잘못되면 예외가 유출될 수 있었습니다. 명시적 검사를 넣어 인증 실패 또는 제공자 장애로 처리합니다.
3. 소셜 표시 이름이 공백·숫자·배열이면 사용자 응답이 계약을 위반할 수 있었습니다. 문자열 정리·길이 제한·기본 이름으로 보완했습니다.
4. quaternion은 명세의 길이 오차 1e-4와 달리 길이 제곱 오차를 검사했습니다. API 및 PLY 검사를 길이 기준으로 맞췄습니다.
5. 결과 geometry JSON의 과도한 중첩 예외를 INVALID_ARTIFACT로 처리하도록 보강했습니다.
6. 파일 시스템 쓰기 실패가 일반 500이 됐습니다. STORAGE_UNAVAILABLE 503/Retry-After를 반환하고 미완성 검증 상태를 남기지 않습니다.
7. README의 워커 예제가 이전 supplementalInputs를 사용했습니다. 실제 v1.1 depths/confidences/roomplan/roomplanStructure로 수정했습니다.

## 재현 방법

백엔드 폴더에서 가상환경 Python으로 실행합니다. 기존 실데이터는 수정하지 않고 임시 저장소를 사용합니다.

```powershell
python -m pip install -r requirements.lock
python -m pytest -q
python -m ruff check app tests scripts/verify_local_tcp.py
python -m ruff format --check app tests scripts/verify_local_tcp.py
python scripts/verify_local_tcp.py
```

전체 반복 행렬까지 포함한 커버리지를 새로 측정하려면 다음을 실행합니다. coverage.json의 이 보고서 수치는 업무·공통 HTTP 검증으로 산정한 값이므로 실행 범위에 따라 소폭 달라질 수 있습니다.

```powershell
python -m coverage run --branch --source=app -m pytest -q
python -m coverage report -m
python -m coverage html -d validation/coverage
```

증빙: validation/summary.json, http-operations.json(각 API 관찰 상태/요청 수), pytest.xml, pytest-python312.xml, tcp.json, coverage.json/coverage HTML. API PDF의 2026-09-30 검증 기록은 이전 실행 기록이며 최신 검증은 본 보고서입니다.
