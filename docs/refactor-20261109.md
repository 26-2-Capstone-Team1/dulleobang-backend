## Python AI 워커

기존 `pr2`의 좌표·방 기하·객체 매핑·메시 처리·점군·파일 기록을 `coordinates`, `room_geometry`, `object_mapping`, `mesh_assets`, `point_cloud`, `artifacts`로 나눴습니다. `pr2`는 결과 검사와 변환 처리 순서를 조립합니다.

`runner`는 큐와 attempt 흐름을 담당합니다. `execution`은 엔진 시작·제한 시간·lease 상실·프로세스 그룹 종료와 회수를, `publication`은 파일 등록·전송·결과 참조 연결·완료 콜백을, `tokens`는 워커 토큰 발급을 담당합니다. 복합 문장과 세미콜론 문장을 여러 줄로 풀었습니다. 실행·감시 중 예외로 벗어나더라도 `finally`에서 살아 있는 엔진 프로세스를 종료·회수하도록 했습니다.
